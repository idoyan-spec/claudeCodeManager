🤔 רגע, מה זה VS Code בכלל?

VS Code הוא סתם חלון עבודה. יש בו הרבה כפתורים, אבל אנחנו משתמשים בו כמעט רק בשביל דבר אחד: להיות "החדר המשותף" שבו כל סשני Claude יושבים בטאבים מסודרים בצד. תתעלם מרוב הכפתורים — נגיד לך בדיוק לאן להסתכל.

חשוב לזכור: הטרמינל בתוך VS Code הוא אותו טרמינל רגיל — הכל עובד בדיוק כמו תמיד, פשוט מסודר יפה יותר.

④הטרמינל + רשימת הטאביםכאן אנחנו חיים. כל סשן Claude = טאב ברשימה שמימין לטרמינל.

⌨️ הטרמינל — כל מה שצריך

  1. לפתוח את הטרמינל: Ctrl+ˋ (המקש מעל Tab, משמאל ל-1). זה מראה/מסתיר את אזור ④.
  2. סשן חדש (טאב חדש): Ctrl+Shift+5, או כפתור ה-+ בפינת הטרמינל.
  3. להריץ פרויקט: בטאב החדש הקלד ccm E:\נתיב\לפרויקט ולחץ Enter.
  4. לעבור בין סשנים: פשוט לחץ על שורה ברשימה שמימין. זהו.
כל טאב נקרא בשם התיקייה שלו + נורית סטטוס. הרשימה אנכית ולכן לא מצטמצמת גם עם הרבה סשנים — בול מה שרצית.

✅ הצעד הראשון שלך

  1. פתח VS Code (מתפריט Start). זהו החדר.
  2. לחץ Ctrl+ˋ — נפתח הטרמינל למטה.
  3. הקלד ccm E:\MAIN_CLAUDE\claudeCodeManager ו-Enter.
  4. מימין תופיע שורה claudeCodeManager — הצלחת! עכשיו נסה עוד אחת בטאב חדש.

רוצה את התמונה המלאה של ה-Manager (התרחיש המלא, טעויות נפוצות)? פתח את USER_GUIDE.html שלצידו.
