# התקנה על מחשב חדש — מדריך לבעל המחשב

**Build: `2026-07-30 11:58 v26 vscode-extensions`**

מדריך זה מיועד למי שמקבל את סביבת העבודה של עידו על המחשב שלו:
VS Code מוכן לעבודה עם Claude Code (טאבים עם סטטוס חי, בורר פרויקטים ב-`Alt+O`,
שומרי סגירה, ייצוא Markdown→PDF בעברית) + **כלי הכתבה קולית** (מחזיקים Ctrl ימני ומדברים).

---

## מה צריך לפני שמתחילים

1. **Windows 10/11**.
2. **VS Code** מותקן — https://code.visualstudio.com
3. **Git** מותקן — https://git-scm.com/download/win (ברירות המחדל בסדר).

זהו — **לא צריך חשבון GitHub ולא שום התחברות**: שני המאגרים ציבוריים (רישיון MIT),
ההורדה והעדכונים עובדים בלי הזדהות. לשנות אותם יכול רק עידו.

> Python 3.10+ נדרש לכלי ההקלטה — אם אין, המתקין ינסה להתקין לבד דרך winget.

## ההתקנה — פקודה אחת

פותחים PowerShell (לא צריך "כמנהל") ומדביקים:

```powershell
git clone https://github.com/idoyan-spec/claudeCodeManager.git
cd claudeCodeManager
powershell -ExecutionPolicy Bypass -File .\scripts\bootstrap.ps1
```

זהו. המתקין עושה הכל לבד: Claude Code, הגדרות VS Code, קיצורי מקשים, הוקים של
סטטוס-על-הטאב, התוסף, **תוספי VS Code** (התוסף של Claude Code, תוסף RTL שמציג
עברית מימין-לשמאל בצ'אט של קלוד, ותוסף Markdown PDF), כלי ההקלטה (משוכפל
לתיקייה שכנה `voice-to-claude`), והרשמת עדכון אוטומטי.

### מה הוא ישאל אתכם

שאלה אחת בלבד: **מפתח Gemini API** (בחינם) — נדרש רק לפיצ'ר "הסבר לי את הטקסט המסומן".
**ההכתבה הקולית עובדת גם בלעדיו** (התמלול כולו מקומי על המחשב, שום דבר לא נשלח לענן).

- משיגים מפתח חינמי בדקה: https://aistudio.google.com/apikey
- מדביקים כשהמתקין מבקש. המפתח נשמר **מוצפן** ב-Windows Credential Manager של
  המשתמש שלכם בלבד — לא בקובץ, לא בגיט, ואף אחד אחר לא רואה אותו.
- אפשר ללחוץ Enter לדלג, ולהריץ שוב את המתקין בעתיד כדי להוסיף.

### אחרי ההתקנה

1. **לפתוח חלון VS Code חדש** (חובה — חלק מההגדרות נקראות בהפעלה).
2. `Alt+O` — בורר פרויקטים. `Alt+E` — סייר קבצים צף. `Alt+Q` — סגירה עם גיבוי.
3. **הכתבה:** מחזיקים **Ctrl ימני** בכל תוכנה, מדברים, משחררים — הטקסט מודבק.
   בפעם הראשונה ההקלטה תתעכב מעט (הורדת מודל התמלול, חד-פעמי).
   השפה נקבעת לפי פריסת המקלדת הפעילה (עברית/אנגלית).
4. **הסבר טקסט:** מסמנים טקסט בטרמינל של VS Code ומחזיקים Ctrl ימני — כרטיס הסבר בעברית.

## עדכונים — אוטומטיים

בהתקנה נרשמת משימה שקטה (`ClaudeCodeManagerUpdate`) שמושכת את הגרסה האחרונה
ומתקינה מחדש **בכניסה למחשב וכל 12 שעות**. כשעידו מעדכן — המחשב שלכם מתעדכן לבד.

- עדכון ידני מיידי: להריץ שוב את אותה פקודת `bootstrap.ps1` מתיקיית הריפו.
- לוג העדכונים: `%LOCALAPPDATA%\ccm\bootstrap-update.log`
- לבטל את העדכון האוטומטי: `schtasks /Delete /TN ClaudeCodeManagerUpdate /F`
  (ואז להריץ bootstrap עם `-NoAutoUpdate` כדי שלא יירשם שוב).

## פתרון תקלות נפוצות

- **"clone failed"** — המאגרים ציבוריים, אז זו כמעט תמיד בעיית אינטרנט. לבדוק חיבור ולהריץ שוב.
- **Python הותקן אבל לא זוהה** — לפתוח PowerShell **חדש** ולהריץ את bootstrap שוב.
- **אין הדבקה אחרי הכתבה** — לבדוק את `service_log.txt` בתיקיית `voice-to-claude`.
- **כרטיס ההסבר לא עובד** — כנראה דילגתם על המפתח; להריץ bootstrap שוב ולהדביק מפתח.
